# Inbox and tidy design

## A. Survey (2026-11-19)
Sources and leftovers are listed in [inbox-sources.md](../notes/inbox-sources.md). steerwright reads each owner's output and never repeats its logic: askwright sweep plus `~/.askwright/sessions/*.json` for unanswered sets, `~/.grindwright/runs.jsonl` for grind state dirs (no disk search; a depth-4 find took over 2 minutes), `## Waiting on Mark` sections in registered HANDOFF files, `gh search prs` both with and without `--owner` (PRs in other owners' repos), `#needs-mark` lines in the backlogs (S/M/L tag gives the Mark-minutes guess), evergreen audit. Projects are matched by path prefix against `paths[]` in the registry, or by askwright project name. Leftovers seen: 49 real worktrees (31 merged, 4 upstream gone, 1 dirty), 74 empty wt folders, many merged branches, 17 local python listeners, a stale `~/.steerwright/server.json` pid, 6 GB of Temp/claude. everkeep and releasewright keep little or stale state, so their collectors fail soft.

## B. Collectors (2026-11-19)
`sw.py inbox` lives in `scripts/inbox.py` (sw.py is past 1500 lines). Eight collectors (prs, ask, ask-unanswered, grind, handoff, backlog, chain, evergreen) each return items `{id, source, kind, title, age_days, link, path, action, minutes, project}`; an exception becomes a note. External commands go through one `run()` that tests replace. Projects map by askwright project name, then by path prefix. A grind WAITING line that points at a listed askwright set is dropped as a duplicate. The PR search uses assignee, needs-review with owner m4bwav, and review-requested: a label search with no owner returned 100 strangers' PRs. The ask `check` pile counts only after 7 days, since it is mostly agent work. First real run: 113 items, about 720 Mark-minutes, 5 s, no failed collector. Cache 15 minutes, `--fresh` skips it.

## C. Inbox page (2026-11-19)
`/inbox` is `inbox.inbox_page()`, routed in `sw._render` and so mounted at `/steer/inbox` in askwright's server. It reads `collect()` (cached 15 minutes; `?fresh=1` reruns). Groups are (project, kind), ordered by their oldest item. Filters are query chips, so links survive the mount rewrite. The under-2-minutes lane sits on top. The tab on every page shows the count from the cache file only, so the dashboard never waits 5 s on the collectors. Unmapped items (backlog lines, PRs by repo) show as no project; mapping them stays open.

## D. One-click clearing (2026-11-19)
askwright mounts steerwright for GET only, and its POST routes need askwright's token, so steerwright cannot run a verb from the page without writing askwright's state itself. Rows therefore get Open (the PR, or the set's page on askwright's server: key is the session record's file stem, first 12 characters, base from `dashboard/server.json`) and, for answered sets, buttons that copy the exact `ask.py consume` or `ask.py dismiss` command. askwright's own Unprocessed tab also has Dismiss. Running verbs from the page would need a POST hook in askwright; left for Mark if he wants it.

## E. Leftover scan (2026-11-19)
`sw.py tidy` lives in `scripts/tidy.py` and is a dry run: it lists and never deletes or kills. Four scanners fail soft. Worktrees come from `git worktree list` of each main clone under `tidy_roots`. A worktree is safe only when clean, older than `tidy_days`, and merged into origin/HEAD, or its remote branch is gone and `gh pr list --head` finds a merged PR (squash merges). Folders named like a worktree with no `.git` are safe when only caches remain, else ask; a folder holding live worktrees (`_wt`) is skipped. Branches: merged is safe; gone with a merged PR is safe (`-D`); gone without one is ask; a branch checked out in a worktree is covered by that row. Servers: netstat listeners joined with `qw.py pid python` and `node`; the process name must start with the pattern, since qw also matches command lines (Code.exe showed as node). Keeper ports and askwright's pid are keep; every other server is ask, because stopping a server this chain did not start needs Mark. A stale `~/.steerwright/server.json` pid is safe (steerwright's own file). Scratch: one row per `Temp/claude/<slug>`, listing its session folders older than `tidy_scratch_days`. Every safe row carries an undo note. First real run, 62 s: 88 worktrees, 70 folders, 479 branches and 3564 scratch slugs safe; 20 ask (15 servers, 4 folders, 1 branch); 72 keep.
