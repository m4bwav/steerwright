# steerwright design note

## Registry
`~/.steerwright/projects.json` (`STEERWRIGHT_HOME` moves it; open question `home` on ask/steerwright-setup).

```
{"steerwright": 1, "wip_limit": 3, "projects": {"<slug>": {
  "name", "paths": [..], "kind": software|game|film|art|music|writing|engineering|other,
  "status": active|tabled|abandoned|done, "goal", "done_when", "target": "YYYY-MM-DD"|null,
  "revisit": "YYYY-MM-DD"|null, "wake": "", "postmortem": {why, keep, date},
  "sources": {"askwright": [names], "chainwright": [ledgers], "grindwright": [states], "handoff": [files]},
  "history": [{ts, event, note}], "items": [{id, title, created, state, done}], "last_review"}}}
```
Other files in the home: `server.json` (steerwright page server), `up.json` (PIDs `up` started), `reviews/<set>/` (askwright review sets steerwright writes in its own home), `config.json` (optional `ask_py`).

## How each sibling is read (read-only, never written)
- **askwright**: `~/.askwright/sessions/*.json` -> set path -> `questions.json` (project name, open questions) + `answers.json` (`answers[qid].state == "answered"`, `updated`). `~/.askwright/projects/*.json` (name, dirs) for discovery. Dashboard URL from `~/.askwright/dashboard/server.json`.
- **chainwright**: `~/.chainwright/runs.json` -> ledgers (`chains.json`: project, chains[state, sessions, history], sessions_total). Temp-dir ledgers (test runs) are skipped. Master page `~/.chainwright/index.html` served at `/sib/chainwright`; `chain_index.py build` refreshes it.
- **grindwright**: `~/.grindwright/runs.jsonl` -> state dirs (`ai-docs/grind`). `ledger.jsonl` items (id, lane, state, created, finished) and `events.jsonl` (types add, claim, done, drafted, ...; `ts`). These feed every flow chart. `~/.grindwright/index.html` at `/sib/grindwright`; `grind_index.py build` refreshes it.
- **continue prompts / HANDOFF**: `ai-docs/plans/*continue-prompt*.md`, `ai-docs/HANDOFF.md` under each project path.
- **activity**: grind events, askwright answer times, chain ledger mtime, HANDOFF mtime, `git log` (26 weeks), dated lines in `ai-docs/log.md`.

## Discovery
Candidates from askwright project dirs, chain ledgers, grind states and `ai-docs/HANDOFF.md` (depth 3 under the Ai folder). Worktrees and side clones fold into the main checkout by git origin URL (or shared git dir); unnamed side copies (`_wt/x`, `x-wt-y`, `wt-x`, `.git` file) are dropped; only folders active in the last `--since` days (30) are proposed. 2026-11-09 run: 63 projects. Grouping into portfolios is open (question `unit`).

## Pages (127.0.0.1, default port 47630)
- `/`: warnings (WIP over limit, tabled projects whose revisit date came), status tiles, current-work strip (chains running, open asks, active in 2 days), table sorted wake, red, amber, green, tabled, done, abandoned.
- `/p/<slug>`: goal, done-when, tiles (done, remaining, cycle time p50/p85, open asks), Monte Carlo forecast (50/85/95 % dates), next actions, burn-up, cumulative flow, throughput per week, activity per week, aging work, askwright sets, chain runs, grind lanes, current continue prompt, HANDOFF head, decision log.
- Charts are inline SVG built by sw.py (no CDN).

## Health
green: activity within 7 days; amber: 8-21; red: more than 21 or none; tabled is grey; wake is blue when the revisit date has come.

## Review
`sw.py review NAME`: findings (stall over N weeks, 85 % forecast past target, over WIP and among the quietest, no definition of done, open asks), a guess (keep / table), next three actions, then an askwright set (decision, next actions, wake condition, post-mortem, shown by answer) served by `ask.py serve`. Mark's answer is applied with `sw.py table|abandon|done|activate`.

## Known gaps (2026-11-09)
- Main page takes ~17 s for 63 projects (git log per path every request): needs a cache.
- No `sw.py apply-review` that reads the review answers and runs table/abandon itself.
- Flow charts exist only for grind ledgers and steerwright items; other projects show the activity chart only.
- Milestones and risks are not modelled yet.
- Reference citations are mostly unopened (see log).
